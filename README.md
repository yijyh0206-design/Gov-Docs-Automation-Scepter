# Gov-Docs-Automation-Scepter
文科生的自動化革命：找回同仁的青春歲月。

# 芙莉蓮的權杖：基層公務員的微型自動化 🪄
> 「如果是欣梅爾的話，一定也會這麼做的。」

宜蘭縣政府計畫處管制考核科的非資訊職系同仁，運用生成式 AI 協同開發（Vibe Coding／規格導向開發 SDD）的逾期公文週報工具。每週逾期公文週報從人工整理約 120 分鐘，縮短為全流程約 1 至 2 分鐘（轉檔清理核心約 2 秒）。

## ✨ 核心理念
- **業務主權**：把解決問題的發言權，交還給最懂業務的人。
- **守護青春**：我們優化的不是報表，而是行政的正義；我們節省的不是工時，而是同仁的青春。

## 目前版本：v1.8.0（115.11.03）
程式放在 `OverdueList_v1.8.0/`。

**公開範圍**：核心轉檔程式，包含跨表去重、機關筆劃排序、逾限天數計算，以及依週報範本產出 .ods 週報。

**未公開的部分**：
- 自動登入公文系統與建管系統、下載報表的模組。這部分涉及機關內部系統，僅供機關間移轉。
- 自動化測試。測試使用機關內部的真實報表，因此未隨公開版釋出。

`範本/公文逾限簡報_範本.ods` 已去識別化，每個分頁只保留一列虛構的樣板列。

## 🛠️ 主要功能
- 讀取 A～G 七類公文清單（CSV），以及列管案件與建管系統人民申請清冊
- 跨表去重（公文系統匯出的文號右側補空白，也能正確比對）
- 機關與單位依首字筆劃排序
- 依行事曆扣除非工作日，計算逾限天數
- 依人工週報範本產出 .ods，保留封面、樣式、下拉選單、篩選與列印設定

## 🚀 如何使用
1. 安裝 Python 3.13，再安裝套件：`pip install -r requirements.txt`
2. 把報表 CSV 放進同一個資料夾，檔名開頭為 `A_`～`G_`（例如 `A_一般公文.csv`）。
3. 執行方式擇一：
   - 視窗版：執行 `OverdueList_v1.7.1.py`，或雙擊 `執行.bat`
   - 不開視窗：`python OverdueList_v1.7.1.py --auto --folder <報表資料夾> --outdir <輸出資料夾>`
4. `範本/行事曆_非工作日.txt` 請依當年度行事曆更新。

核心程式檔名沿用 v1.7.1。v1.8.0 的建管系統分頁功能已包含在這個檔案中，其餘改版集中在未公開的報表擷取模組。
