# 芙莉蓮的權杖：基層公務員的微型自動化革命 🪄
> 「如果是欣梅爾的話，一定也會這麼做的。」
這是一個由「非資訊職系」承辦人自發開發的工具，旨在解決政府機關內瑣碎、高頻且磨人的公文管考數據處理。

## ✨ 核心理念
- **業務主權**：把解決問題的發言權從工程師手中，重新交還給最懂業務的承辦人。
- **行政減量**：將 240 分鐘的人工勾稽，縮短為 5 分鐘的自動化運算。
- **守護青春**：我們優化的不是報表，而是行政的正義；我們節省的不是工時，而是同仁的青春。

## 🛠️ 主要功能 (Vibe Coding 實踐)
- **智慧去重**：自動判別 A/B/F/G 類案件優先級，確保數據正義。
- **筆劃排序**：內建中文字首筆劃引擎，產出符合公務嚴謹格式的報表。
- **一鍵彙整**：自動生成跨單位統計總表，並封裝樣式美觀的 Excel 檔案。

## 🚀 如何使用
1. 下載 `gov_docs_batch_part23.py`。
2. 確保環境已安裝 `pandas`, `openpyxl`, `tkinter`。
3. 執行程式，揮動你的自動化權杖。
